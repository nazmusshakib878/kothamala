# 🎙️ KothaMala (কথামালা) — Ultra-Premium Voice-First Social Mobile App

> **"Your Voice. Your Story. Your Community."**
> একটি আধুনিক, লাক্সারি এবং ভয়েস-ফার্স্ট সোশ্যাল মিডিয়া মোবাইল অ্যাপ্লিকেশন যা বাংলাদেশের কণ্ঠকে বিশ্বের দরবারে তুলে ধরতে তৈরি।

---

## ✨ Features (ফিচারসমূহ)

* **💎 Ultra-Premium UI/UX:** Titanium chassis frame mockup with dynamic specular lighting and obsidian dark mode.
* **🏝️ Dynamic Island 2.0:** Live tracking of currently playing audio with interactive expanding pill and camera sensor glint.
* **🎙️ Create Studio:** Real-time waveform audio recording with sound effects, background music (Rain, Guitar, Flute), Bengali Speech-to-Text auto-captioning, and AI summary generation.
* **🔴 Live Audio Stage:** Clubhouse / Twitter Spaces-style virtual audio room with interactive audience live polls, stage chat, speaker pulsing rings, and raise hand queues.
* **🎵 Duet & Audio Threads:** Voice-based threads, reply chains, and duet practice (e.g. Spoken English 30-day challenge).
* **📹 Vertical Shorts:** TikTok/Reels-style vertical audio-video shorts with rotating vinyl disc, equalizer, and double-tap interactions.
* **💬 Voice Messenger & Calling:** Encrypted audio/video calling simulation, direct voice notes with playable waveform previews, and auto-caption transcripts.
* **🎧 Spatial Player & Scrubbing:** Full-screen modal player with interactive waveform seeking, speed toggle (1.0x - 2.0x), and sleep timer.
* **💰 Creator Studio:** Monetization dashboard with listener hours, ranking, and bKash / Nagad withdrawal flows.

---

## 🛠️ Tech Stack

* **Frontend:** Modern Vanilla HTML5, CSS3 (Custom Properties, Glassmorphism, Specular Lighting, CSS Grid/Flexbox)
* **Audio Engine:** Native Web Audio API Synthesizer (Zero external audio file dependency)
* **Fonts:** `Plus Jakarta Sans` & `Hind Siliguri` (Google Fonts)
* **Icons:** Ultra-sharp, scalable inline SVG icons
* **Deployment:** Vercel Static Hosting
